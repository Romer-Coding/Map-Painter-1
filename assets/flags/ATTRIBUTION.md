# Flag Attribution

These files are a direct copy of the historical-era flag set from
`Games/Map Painter 2/assets/flags/` (fetched from Wikimedia Commons by
`Scripts/fetch_flags_wikimedia.py`). See that project's own
`assets/flags/ATTRIBUTION.md` for the per-file Commons source, license, and
artist/credit for every tag/variant here — it is the source of truth; this
copy does not maintain a separate ledger.
